# Security Policy

PickUI is a static component library and docs site: it has no backend, accounts or secrets.

If you find a security problem (for example an XSS vector in a component or in the docs site), please
**do not open a public issue**. Report it privately via
[GitHub Security Advisories](https://github.com/hamza-guetioui/pickui/security/advisories/new)
or the contact form at https://guetix.com/#contact. You'll get a reply as soon as possible, and a fix will
be released before the details are made public.
